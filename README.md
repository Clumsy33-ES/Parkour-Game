# 2D Parkour Game (Unity)

A 2D parkour-style platformer game developed with Unity.  
The project is currently in early development and includes only basic mechanics.

## 🎮 Game Overview
- Genre: 2D Parkour / Platformer
- Engine: Unity
- Perspective: 2D (Side-scroller)
- Status: In development (early stage)

The game focuses on basic movement mechanics where the player navigates platforms and obstacles using precise timing.

## 🛠 Technologies Used
- Unity Engine
- C#
- 2D Physics (Rigidbody2D, Colliders)
- Unity Input System

## ✨ Current Features (Basics)
- Horizontal movement
- Jump mechanic
- Basic collision detection
- Simple level layout

## 🚧 Planned Features
- Advanced parkour mechanics (double jump, wall jump)
- More levels
- Animations
- UI (start menu, pause menu)
- Sound effects

## 📁 Project Structure
- `Assets/` – Scripts, sprites, scenes
- `Packages/` – Unity packages
- `ProjectSettings/` – Project configuration

> Note: Library, Temp, and Logs folders are excluded using `.gitignore`.

## ▶️ How to Run
1. Clone the repository
2. Open the project with **Unity Hub**
3. Select the correct Unity version
4. Press **Play** to test the game
